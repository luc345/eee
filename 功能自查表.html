八、关于防火墙 / SmartScreen 弹窗

先说清楚：本工具不开任何端口、不监听任何东西。 代码里没有 socket / bind / listen，只做出站 HTTP（访问 OJ 查作业、下载 WorkBuddy 安装包）。 所以不存在「入站规则」需要放行，弹窗不是"程序要当服务器"引起的。
弹窗真正原因怎么处理
「Windows Defender 防火墙已阻止此应用的部分功能」/ 是否允许访问网络 系统看到一个没有版本信息、没有签名的 exe 要联网，就按"未知程序"问你一次 勾 专用网络 即可（不用勾公用网络）。直接关掉也行，它不影响出站访问。
「Windows 已保护你的电脑」蓝色 SmartScreen exe 没数字签名，且下载来源是"Internet 区域"标记 点「更多信息」→「仍要运行」；或右键 exe → 属性 → 勾「解除锁定」
杀软报可疑 PyInstaller 打包的 exe 被启发式规则误判（这类打包器常被滥用） 加个排除项，或改用下面的 Python 方式跑

已经做的两个改进

  1. 给 exe 加了版本信息与 manifest：现在系统能读到 FileDescription / ProductName / CompanyName / FileVersion， 不再是一个"无名可执行文件"；manifest 声明 asInvoker（不要管理员权限）， 减少 UAC 与安全软件告警。
  2. 启动器优先用 python.exe 跑源码：启动器.bat 会先找 Python （先 WorkBuddy 自带的，再 PATH 里的），找到就 python oj_share\oj_setup.py。这时联网的是已受信任的 python.exe， Windows 不会为它弹"未知程序"对话框。找不到 Python 才回退到 exe。

想彻底不要弹窗，就保持 oj_share\ 文件夹和启动器放在一起（分享包里就是这么放的）。
