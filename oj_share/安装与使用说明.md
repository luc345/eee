# OJ 作业自动检测与提交 · 分享包（多助手版）

把这套「一句话 → 检测老师新作业 → 写 C/C++ 代码 → 本地测试 → 自动提交 OJ → 整理收尾文件夹 → 汇报」
的能力，装到你自己电脑上的 AI 助手里。

**支持三种 AI 助手，装的时候自己选一个：**

| 你的助手 | 技能包装到哪 | 怎么触发 |
|---|---|---|
| **DSH**（DeepSeek Harness） | `~\.dsh\skills\` | `/oj-homework-checker` 或说一句话 |
| **WorkBuddy**（腾讯） | `~\.workbuddy\skills\` | 说一句话，或技能面板点「运行技能」 |
| **TRAE CN**（字节） | `~\.trae-cn\skills\` | `/oj-homework-checker` 或说一句话 |

> ⚠️ **本包不含任何账号密码**，所有个人信息由使用者自己填。
> 本包也**不建定时任务**：什么时候跑由你说了算，一句话就叫它干活。

---

## 零、最简单的安装方式（推荐）

双击 **`启动器.bat`**（或直接双击 `OJ作业自动化配置助手.exe`，效果一样）：

1. **先选你的 AI 助手**：`1) DSH` / `2) WorkBuddy` / `3) TRAE CN`
   - 没装 WorkBuddy？在这一屏直接按 **`d`**，助手会去官网查最新版安装包并帮你下载；
   - 不确定选哪个？按 **`?`** 看对应助手的安装指引。
2. 回到菜单，选 **`2. 一键配置`**，它会先检测环境（助手 / Python / C++ 编译器 / 网络能不能通 OJ）
3. 缺什么按它给的链接装好
4. 按提示填学号、密码、老师姓名、收尾文件夹位置
5. 它会自动生成 `config.json`、部署脚本、把技能包装到你那个助手的目录里，
   并打印一句「触发口令」和完整的任务内容
6. 回到你的助手，输入那句口令（或把任务内容整段粘进对话），它就开始干活

**菜单里还有什么**：

| 选项 | 作用 |
|---|---|
| 1 检测本机环境 | 看助手 / Python / 编译器 / 网络齐不齐 |
| 2 一键配置 | 检测 + 填信息 + 部署脚本 + 装技能包 |
| 3 立刻跑一次检测 | **不开 AI**，直接跑 `oj_checker.py` 看有没有新作业 |
| 4 查看当前配置 | 看 config.json（密码打码） |
| 5 打开脚本目录 / 收尾文件夹 | 直接跳到文件所在位置 |
| 6 查看软件安装指引 | 缺什么装什么的链接 |
| 7 更换 AI 助手 | 换宿主 |
| 8 下载 WorkBuddy 安装包 | 单独入口 |

> `启动器.bat` 必须和 exe 放在同一个文件夹里，而且**必须是 CRLF 行尾**——
> 如果你用某个编辑器改过它、把行尾变成了 LF，cmd.exe 会解析错乱（报
> `'utomation' is not recognized` 这种），用记事本另存或重新复制一份即可。

下面的手动步骤是给想自己折腾的人看的。

## 二、接收方怎么装（4 步）

### 1. 安装技能包
把 `oj-homework-checker` 整个文件夹放到**你所选助手**的技能目录：

| 助手 | 放这里 |
|---|---|
| DSH | `C:\Users\<你的用户名>\.dsh\skills\` |
| WorkBuddy | `C:\Users\<你的用户名>\.workbuddy\skills\` |
| TRAE CN | `C:\Users\<你的用户名>\.trae-cn\skills\` |

放好后重启一下助手，让它重新加载技能。

### 2. 放脚本
把 `oj_homework` 文件夹放到你想让 AI 干活的工作目录下，例如：

```
C:\Users\<你的用户名>\dsh-oj\oj_homework\          （DSH）
C:\Users\<你的用户名>\WorkBuddy\<项目名>\oj_homework\  （WorkBuddy）
C:\Users\<你的用户名>\trae-oj\oj_homework\          （TRAE CN）
```

### 3. 填自己的信息
复制一份配置模板并填写（**不要直接改 example**）：

```bash
copy oj_homework\..\config.example.json  oj_homework\config.json
python oj_homework\oj_config.py set student_id 你的学号
python oj_homework\oj_config.py set student_password 你的OJ登录密码
python oj_homework\oj_config.py set contest_password 你的作业密码
python oj_homework\oj_config.py set teachers 老师姓名
python oj_homework\oj_config.py set deliver_dir D:\我的OJ作业      # 可选，默认桌面\OJ作业
python oj_homework\oj_config.py show          # 核对（密码会打码显示）
```

### 4. 一句话触发
打开 `自动化任务内容-模板.md`，把里面的 `<PYTHON>` / `<DIR>` 换成自己的路径，
然后在你的助手里说一句：

> 用 oj-homework-checker 技能看看老师有没有发新作业，有就写完测完提交。

或者直接 `/oj-homework-checker`。想让它定期自己跑，用你助手自带的定时任务功能，
把这份任务内容填进去即可（本包不负责建定时任务）。

## 三、需要按自己电脑改的 3 处（重要）

| 位置 | 本机示例 | 要改成 |
|---|---|---|
| Python 路径 | `C:\Users\<你的用户名>\.workbuddy\binaries\python\versions\3.13.12\python.exe` | 你自己助手的 Python 绝对路径（或系统 `python`） |
| 脚本目录 | `C:\Users\<你的用户名>\WorkBuddy\<项目名>\oj_homework` | 你放 `oj_homework` 的实际目录 |
| VS 编译器路径 | `D:\VS\VC\Auxiliary\Build\vcvarsall.bat`（在 `build_and_test.bat` 里） | 你的 Visual Studio 安装路径 |

没装 Visual Studio 也能编译：装 VS 时勾选「使用 C++ 的桌面开发」即可；
或者改用 g++（把编译脚本里的 `cl /nologo /utf-8 /EHsc /std:c++17` 换成 `g++ -std=c++17 -o`）。

## 四、它干活的流程（六步）

1. **检测新作业** —— 拉作业列表，按老师过滤，和 `state.json` 对比找出新作业
2. **写码 + 本地测试** —— 每题一份源码，样例全部比对通过才允许提交
3. **自动提交** —— 每题完整走一遍验证码流程（看图读数，绝不猜、绝不复用）
4. **盯结果，不过就换方法重来，单题最多 3 遍** —— 三次都不过就**停手并警告你**，
   不会无声无息地反复重试耗 token
5. **整理收尾文件夹** —— 每道题的代码按 OJ 题号命名放好，方便直接交：

```
桌面\OJ作业\<作业目录>\
    1-1-a.cpp      ← 题号照抄 OJ 上的编号
    1-1-b.cpp
    汇报.md        ← 每题一行 + OJ 状态链接
```

6. **汇报** —— 对话里报一次，同时写成 `汇报.md`

收尾文件夹位置可以随时改：

```bash
python oj_homework\oj_config.py set deliver_dir D:\期末作业\OJ
```

## 五、对方运行的前提

- 装了上面三个助手中的**任意一个**（活儿是它干的）
- 能访问目标 OJ 站点
- 装了 Visual Studio 的 C++ 工具集（或 g++）
- 电脑开着、助手在运行（你叫它的时候）

## 六、隐私提醒

- 转发前请确认 `config.json` / `config.example.json` 里**没有你的学号和密码**（本包已全部清空）。
- 如果只需要检测不需要自动提交，把配置里的 `auto_submit` 设为 `false` 即可。
