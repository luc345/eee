OJ 作业自动化 · 分享包（多助手版）
================================

【推荐：给别人用】双击这个就能用（两个等价，喜欢哪个点哪个）：
    启动器.bat
    OJ作业自动化配置助手.exe
  第 0 步先让你选平时用的 AI 助手（三个都能用）：
      1) DSH（DeepSeek Harness）
      2) WorkBuddy（腾讯）
      3) TRAE CN（字节）
    没装 WorkBuddy？在这一屏直接按 d，助手会去官网查最新版并帮你下载安装包。
  选完进入菜单：
    1. 检测本机环境        —— 看助手 / Python / C++ 编译器 / 网络齐不齐
    2. 一键配置            —— 检测 + 填信息 + 部署脚本 + 装技能包
    3. 立刻跑一次检测      —— 不开 AI，直接看有没有新作业
    4. 查看当前配置        5. 打开脚本目录 / 收尾文件夹
    6. 查看软件安装指引     7. 更换 AI 助手      8. 下载 WorkBuddy
  （单个 exe，无需装 Python，Windows 可直接运行）

  ※ 启动器.bat 必须和 exe 放在同一个文件夹，且要保持 CRLF 行尾
    （用会改成 LF 的编辑器另存会让 cmd 报 'utomation' is not recognized 这类错）。

【注意】本包不建定时任务。想跑的时候一句话叫它干活即可；
        想定期自动跑，用你助手自带的自动化/定时任务功能，把任务内容填进去。

【作业做完后】它会按 OJ 上的题号把每道题的代码整理到收尾文件夹，方便直接交：
    桌面\OJ作业\<作业目录>\1-1-a.cpp、1-1-b.cpp … 和 汇报.md
  位置可以在配置时改，也可以之后用 oj_config.py set deliver_dir 改。

【功能清单 / 本机装在哪】浏览器打开：
    功能自查表.html

【转发给别人】发这个压缩包就行：
    OJ作业自动化-分享包.zip

【自己查看/修改】看这个文件夹：
    oj_share\
      ├─ 安装与使用说明.md            <- 手动安装的 4 步指引 + 菜单说明
      ├─ 自动化任务内容-模板.md        <- 任务内容模板，照抄即可
      ├─ oj_setup.py                  <- 配置助手源码（exe 就是它打包的）
      ├─ oj_setup_assets\             <- 助手的随包资源
      ├─ oj-homework-checker\         <- 技能包（三个助手通用格式）
      └─ oj_homework\                 <- 脚本副本

注意：包里不含任何账号密码，接收方需要填自己的学号、
      登录密码、作业密码和老师姓名。
